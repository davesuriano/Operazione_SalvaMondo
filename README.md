# Sisal Bet Tracker
Questo è un programma Python che ti permette di tenere traccia delle scommesse fatte sulla piattaforma Sisal.

## Funzionalità
- Puoi aggiungere scommesse fatte sulla piattaforma Operazione_SalvaMondo e tenere traccia di esse.
- Il programma memorizza le informazioni su ciascuna scommessa, inclusi dettagli come data, importo scommesso, evento scommesso, quota e stato della scommessa.
- Puoi visualizzare un riepilogo delle tue scommesse e controllare lo stato attuale di ciascuna scommessa.
## Installazione
1. Assicurati di avere Python installato sul tuo sistema. Puoi scaricare Python dal sito ufficiale.
2. Clona o scarica il repository su GitHub.
3. Naviga nella directory del progetto.
4. Esegui il programma utilizzando il comando python Operazione_Vark.py.
## Utilizzo
1. Avvia il programma eseguendo python Operazione_Vark.py.
2. Segui le istruzioni visualizzate sullo schermo per aggiungere nuove scommesse, visualizzare un riepilogo delle scommesse fatte o controllare lo stato di una scommessa specifica.
3. Puoi aggiungere scommesse inserendo manualmente i dettagli o importando un file CSV con le informazioni sulle scommesse.
